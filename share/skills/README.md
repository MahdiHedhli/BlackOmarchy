# Agent Skills

Plain `SKILL.md` packages (YAML frontmatter + markdown). Not Grok-only.

- `black-omarchy` — this host
- `black-omarchy-pentest` — authorized testing

Copy each folder into whatever skill directory your agent already
scans, or run `sudo ./bootstrap.sh` which installs them for common
agents. See `AGENTS.md` and `docs/agent-skills.md`.
